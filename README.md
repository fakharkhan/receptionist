# AI Receptionist

This project is an AI-powered receptionist that simulates front desk operations, including:

- Responding to online inquiries promptly.
- Answering incoming calls politely.
- Scheduling appointments efficiently.
- Verifying patient insurance information.
- Managing tasks and appointments smoothly.

## Features

- **Interactive Command-Line Interface:**  
  Easily interact with the AI Receptionist using text commands.

- **Task Management:**  
  Add, list, and complete tasks to keep track of front desk duties.

- **Appointment Scheduling:**  
  Schedule, list, and cancel appointments.

- **Call Handling & Insurance Verification:**  
  Simulated call answering, transferring, and basic insurance verification with placeholders for production APIs.

- **Online Inquiry Response:**  
  Promptly answer common questions about working hours, location, and more.

- **Data Persistence:**  
  Tasks and appointments are saved to JSON files for data persistence between sessions.

- **Logging:**  
  All interactions and errors are logged for monitoring and debugging.

- **Production Integration:**  
  Placeholder functions to integrate with external APIs (e.g., Twilio for calls) using environment variables.
